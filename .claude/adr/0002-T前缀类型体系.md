# T 前缀 + type-only + 模块基类继承的类型体系

所有业务类型用 `type` 声明并加 `T` 前缀（`TUserInfo`、`TUserListReq`、`TUserListResp`），模块公共字段提取到 `T{X}Base` 供该模块类型继承，派生差异用 `Omit` / `Pick` / 交叉类型表达，禁止 `any`。Props / Emits 类型不加 `T`。

选此是因为 T 前缀在类型名与变量名之间建立视觉区分（`script setup` 中两者同处一个作用域），type-only + 基类继承让模块字段单一来源、后端字段变更只改基类一处，禁 any 强制类型收窄。代价：命名冗长、新人有学习成本，换来可 grep、可推导、可单点修改。
