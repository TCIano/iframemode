# .claude 子目录规则（SOP 知识体系）

本目录承载项目 SOP（标准作业流程）体系，约束人与 Agent 的协作方式。父级项目规则见项目根 `AGENTS.md`。

## 目录结构

- `sop/通用/01-对话规范.md` ~ `09-自动校验规范.md` — 通用协作、命名、代码约束、提交、自检、API、组件、状态、自动校验
- `sop/技术栈/vue-ant-design.md`、`vue-pinia.md` — 技术栈实施规范
- `CLAUDE.md` — legacy 项目指令（保留，不修改）

## 约定

- 场景化引用：按「任务 → 至少读哪些 SOP」路由表选择，宁可多读不遗漏
- 改 `src/api/` 读 06-api设计规范；改组件读 07-组件设计规范；新建页面读 `sop/技术栈/vue-ant-design.md`；输出代码后跑 05-自检清单；提交前跑 04-提交规范
- SOP 是有生命力的文档：Agent 连续犯同类错时，把错误抽象成新规则补进对应 SOP 文件
