# 命名规则

> 目标：项目中涉及命名的都有统一约定，减少风格不一致导致的阅读成本。

---

## 文件与目录

| 项目          | 规则          | 示例              | 备注                               |
| ------------- | ------------- | ----------------- | ---------------------------------- |
| 组件文件      | PascalCase    | `BasicUpload.vue` | 与组件名一致                       |
| 普通文件/目录 | camelCase     | `useTrendOpt.ts`  | 包括 hooks、utils、api、views 目录 |
| 测试文件      | `xxx.spec.ts` | `auth.spec.ts`    | 可以加 `.test.` 代替 `.spec.`      |

## 代码标识符

| 项目                | 规则                    | 示例                              |
| ------------------- | ----------------------- | --------------------------------- |
| 组件名              | PascalCase              | `UserProfile`, `BasicTable`       |
| 组合式函数（hooks） | `use` 前缀 + PascalCase | `useAuth`, `useGetTrendOpt`       |
| 普通函数/方法       | camelCase               | `fetchData`, `handleClick`        |
| api 请求函数        | camelCase + `Api` 后缀  | `fetchUserListApi`                |
| 常量                | UPPER_SNAKE_CASE        | `MAX_RETRY_COUNT`, `API_BASE_URL` |
| 枚举成员            | PascalCase              | `Role.Admin`, `Status.Active`     |

## 类型与接口

| 项目       | 规则                 | 示例              |
| ---------- | -------------------- | ----------------- |
| 类型别名   | PascalCase，前置 `T` | `TUserInfo`       |
| 接口       | PascalCase           | `UserInfoProps`   |
| Props 接口 | 组件名 + Props       | `BasicTableProps` |
| Emits 接口 | 组件名 + Emit        | `BasicTableEmit`  |

## CSS 类名（简化 BEM）

> 采用块（Block）→ 元素（Element）→ 修饰符（Modifier）三层命名，配合 Vue scoped 使用，避免纯 BEM 的冗长。

| 项目           | 规则                                           | 示例                                                |
| -------------- | ---------------------------------------------- | --------------------------------------------------- |
| 块（组件根）   | 组件名转 kebab-case，不加后缀                  | `drawer-dialog`、`user-form`、`tree-wrapper`        |
| 元素           | `块__元素`（双下划线）                         | `user-form__footer`、`tree-wrapper__tree`           |
| 修饰符（变体） | `块--修饰` / `块__元素--修饰`（双连字符）      | `tree-wrapper--collapsed`、`user-form__item--error` |
| JS 状态类      | `is-xxx` 前缀，仅表示临时 JS 驱动状态          | `.is-active`、`.is-loading`                         |
| 嵌套深度       | 选择器嵌套 ≤ 2 层（块 → 元素），避免特异性膨胀 | —                                                   |
| 全局 class     | 谨慎使用，优先 scoped                          | —                                                   |

**Stylelint 类名正则**（selector-class-pattern）：

```regex
^[a-z][a-z0-9]*(-[a-z0-9]+)*((__|--)[a-z0-9]+(-[a-z0-9]+)*)*$
```

- 禁止驼峰 / 纯下划线类名
- 覆盖 Ant Design Vue 组件内部样式时，用 scoped + `:deep()`，不依赖组件内 class 命名

## 目录命名

| 目录     | 命名约定                          |
| -------- | --------------------------------- |
| 页面组件 | camelCase（与 URL path 风格对齐） |
| 通用组件 | 同上，用有意义的名词              |
| api 模块 | 单个单词，文件名与功能对应        |
