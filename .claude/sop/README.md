# SOP 规范索引

> 本目录是 iframeMode-template 开发规范的唯一入口：文件索引、按任务读取表、组合场景、脚手架对应都在此维护。 AGENTS.md 只保留常驻内容与指向本文件的指针。 通用规则约束跨技术栈的工程行为，技术栈规则约束 Vue 3 + Ant Design Vue 的具体实现。 约定术语定义见根目录 `CONTEXT.md`（模块、契约、深模块、简化 BEM 等），技术决策记录见 `.claude/adr/`。

## 规则优先级

发生冲突时按以下顺序处理：

1. 实际工具配置和源码契约：`package.json`、ESLint、Stylelint、TypeScript、Husky、运行时代码
2. 本目录中的 SOP：开发决策、命名、分层和人工检查规则
3. `README.md`：项目入口和快速开始说明

如果文档与工具或源码不一致，应先修正文档或配置，再继续扩展模板，不要在代码中保留两套互相矛盾的约定。

## 按任务读取

> 表格是保底起点，不是白名单。实际执行时按「你实际创建/修改了哪些文件」动态补充——例如新建页面时如果同时创建了 API、类型、组件文件，就要额外读对应规范。

| 你的任务                  | 至少读这些（起点，非白名单）                                                |
| ------------------------- | --------------------------------------------------------------------------- |
| 首次接项目 / 不熟悉规则   | 02-命名规则 → 03-代码约束 → 技术栈/vue-core（vue-pinia、vue-antd 按需触发） |
| 新建模块 / 页面           | 03-代码约束（类型继承规则）→ 技术栈/vue-core（目录结构）                    |
| 给模块加 API              | 06-api设计规范 → 03-代码约束（类型约束）                                    |
| 改动 / 设计组件           | 07-组件设计规范 → 技术栈/vue-core（组件写法）→ 技术栈/vue-antd（AntD 用法） |
| 设计数据流 / 决定状态放哪 | 08-状态管理规范 → 技术栈/vue-pinia（实施写法）                              |
| 输出代码后                | 05-自检清单                                                                 |
| 提交代码前                | 04-提交规范                                                                 |
| 修复 bug / 排查问题       | 涉及什么读什么（组件→07、接口→06、数据流→08）→ 完成后跑 05-自检清单         |
| 想了解哪层拦截哪层放过    | 09-自动校验规范                                                             |

## 脚手架对应 SOP

| 命令                                | 生成内容                                                | 对应 SOP                                 |
| ----------------------------------- | ------------------------------------------------------- | ---------------------------------------- |
| `npm run gen:api <模块名>`          | `src/api/xxx.ts` + `src/types/xxx.ts`                   | 06-api设计规范 + 03-代码约束（类型继承） |
| `npm run gen:api <业务域>/<模块名>` | `src/api/<业务域>/xxx.ts` + `src/types/<业务域>/xxx.ts` | 06-api设计规范 + 03-代码约束（类型继承） |
| `npm run gen:page <页面名>`         | `src/views/xxx/` 页面骨架 + components                  | 技术栈/vue-core（目录结构）              |
| `npm run gen:component <组件名>`    | `src/components/Xxx.vue`                                | 07-组件设计规范 + 技术栈（组件写法）     |

## 自动检查与人工检查

自动工具负责语法、类型、格式、样式和提交格式等机器可判断的问题。组件职责、目录归属、API 聚合、类型复用和状态分层等设计问题，必须按 `通用/05-自检清单.md` 逐条自检。

- 自动修复：`npm run lint`、`npm run format`
- 纯检查：`npm run lint:check`、`npm run format:check`
- 类型检查：`npm run type-check`（`pre-commit` 不执行，提交前手动跑，构建 / CI 兜底）
- 构建检查：`npm run build`
